# ⚾ Pitching Visualization & Biomechanics Analyzer

An interactive, synchronized 3D motion capture and kinematics visualization dashboard for baseball pitching mechanics.

## 🚀 Live Demo
- **Web App / Mobile:** [https://menosterra.github.io/visualization-pitching/](https://menosterra.github.io/visualization-pitching/)

## ✨ Key Features
- **Multi-Angle Synchronized 3D Views**: Top View (Overhead), 3rd Base View (Side), and Catcher View (Front).
- **Interactive Kinematics Chart**: Real-time Pelvis (Hip) Rotation, Torso (Shoulder) Rotation, and Hip-Shoulder Separation (X-Factor) curves.
- **Biomechanical Events**: Annotated time markers for Leg Lift, Foot Plant, and Ball Release.
- **Responsive Mobile Support**: Optimized for desktop 2x2 grid and touch-friendly mobile 1-column layout.
